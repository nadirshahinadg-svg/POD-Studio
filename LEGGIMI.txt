POD STUDIO V2 — AGGIORNAMENTO GITHUB PAGES

1. Nel repository POD-Studio scarica prima una copia della V1 (Code > Download ZIP) come backup.
2. Estrai POD_Studio_V2.zip sul telefono.
3. GitHub > repository > Add file > Upload files: seleziona i file estratti.
4. Carica nella RADICE del repository. Per i file esistenti GitHub puo' richiedere la sostituzione; se l'interfaccia mobile non consente di sovrascrivere, usare github.dev da browser desktop oppure modificare i file singolarmente.
5. Conferma Commit changes e attendi Pages Actions con segno verde.
6. Riapri l'app con connessione attiva, chiudila e riaprila se necessario: la cache offline viene aggiornata dal service worker V2.
7. Verifica anteprima, 10 test, download PNG, modalita' offline.

NOTE: Il poster ha dimensioni 3600 x 4800 px, adatte nominalmente a 12x16 a 300 PPI. I metadati DPI non sono garantiti dal browser. Non e' stata verificata la compatibilita' con le specifiche di bleed e stampa di Printify. I 10 test verificano il layout via software, non la stampa.
